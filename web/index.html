Not connected. Tap Connect to join the shared simulator.

Use the D-pad, A/B, Menu, and draggable crank to control the game. Control behavior depends on the loaded game. One browser can control the shared simulator at a time.

Audio requires server opt-in and a tap on Enable audio. Start at 0 dB and raise boost if needed. Quality and synchronization depend on the host/network. Linux simulator support is experimental; actual iOS and physical-device behavior is not established by this bridge.
